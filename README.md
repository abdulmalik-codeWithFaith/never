# WhatsApp Clones

This project is a front-end representation of a chat application, mimicking the look and feel of WhatsApp. It displays a static list of chats in a sidebar, and a main chat area.

## Features

- Responsive chat interface layout.
- Displays a list of predefined chats with avatars, names, last messages, and timestamps.
- Placeholder for chat header with chat name and last seen status.
- Placeholder for message input area.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository:
   ```bash
   git clone <repository_url>
   ```
2. Navigate to the project directory:
   ```bash
   cd whatsapp-clones
   ```
3. Open `index.html` in your web browser.
